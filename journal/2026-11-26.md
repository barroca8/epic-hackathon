# 2026-11-26

## How six people and six Claudes work together

Question: a shared Google Doc, a quick Linear, or something else?

Conclusion (D-01): one private GitHub repo. Claudes read and write files natively on every PC with no
extra setup. A Google Doc needs a connector on all six machines and has no structure; Linear costs setup
time for a board that a markdown table covers. The two prep runs (`hackaton-epic`, `hackaton-epic-2`)
already worked from `PRD.md`, `NEXT_STEPS.md` and `journal/`, so this is the same habit for six people.

Three rules carry it:

1. One writer per file, so there are no merge conflicts.
2. One source for numbers (`facts.md`). In prep, Claude invented "39 of 50 EVs" when the real count was
   42; six Claudes recounting separately would give six figures.
3. Pull before starting, push after every finished ticket.

Roles proposed for six: captain / integrator, data, analysis, app / report, critic, pitch.

Open: the shared `CLAUDE.md` waits for more insight into the challenge format (D-02). The five
teammates still need to be invited, and all six need git and a GitHub account.
